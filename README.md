# CV en une 

CV personnel en une page, créé en HTML et CSS.

## Aperçu

Démo en ligne : https://chattouhiikram.github.io/Single-page-cv/
page
## Fonctionnalités

- Mise en page en deux colonnes (profil et compétences à gauche, parcours à droite)
- Design responsive : lisible sur ordinateur et sur téléphone
- Prêt à imprimer ou à enregistrer en PDF au format A4

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, variables CSS, media queries)

## Structure du projet

- `index.html` : contenu du CV
- `style.css` : mise en forme

## Utilisation

1. Télécharger ou cloner le projet
2. Ouvrir `index.html` dans un navigateur
3. Pour obtenir un PDF : Ctrl + P, puis « Enregistrer au format PDF »
